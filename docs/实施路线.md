# Proposed实施路线

2026-11-02用户确认以下顺序。本文只保存稳定路线；当前进度与完成记录见 [TASKS.md](../TASKS.md)。

**先完成Proposed，再从同一实现派生其他对照；MISOCP独立补做优化验证。**

| 顺序 | 工作 | 阶段验收 |
|---|---|---|
| 1 | 冻结33节点系统配置 | 区域、设备、容量、编号及接口明确 |
| 2 | 数据处理＋潮流环境 | 完整运行一天96步；潮流收敛，OLTC/SC/PV作用方向和奖励正确 |
| 3 | PPO智能体与预训练 | 随机机械设置下可学习，权重和验证结果可追溯 |
| 4 | LLM智能体与离线经验改进 | 合法日前计划、相似日检索、3轮Reflexion、经验库更新 |
| 5 | 冻结LLM，微调PPO | 固定经验库后，PPO适应LLM日前计划，形成完整Proposed |
| 6 | 独立测试 | 冻结全部更新，输出偏差、越限率、合规率和成本 |

后续由Proposed派生No-PT、No-Reflexion及其他对照。MISOCP读取同一网参、设备与场景，优化结果回代同一AC潮流环境；准确未来节点预测属于理想信息参照，单独标注。

三个核心模块是仿真环境、PPO智能体、LLM智能体；数据与训练/验证编排共用配置。

开工前充分讨论即可，不要求为上述每一步预建任务卡。执行结束后记录实际结果，实验无提升或失败也应如实说明。
