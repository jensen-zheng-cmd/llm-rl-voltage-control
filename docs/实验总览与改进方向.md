# 实验总览与下一步方向

更新于 2026-11-09。本文汇总本项目已经执行的实验和数值，结果入口见 [results](../results/README.md)。

## 实验基础与评价口径

- 系统为 Baran–Wu 33 节点网，负荷和光伏来自 MAPDN 加工时序。OLTC、电容器、PV 节点与约束按本项目已冻结配置实现。
- 数据分为训练 731 天、验证 181 天、最终测试 184 天。每个仿真日 96 个 15 分钟等效时段，使用平衡 AC 潮流评价。
- 平均绝对电压偏差按全节点全时段的 |V−1| 取平均，越限率按节点时段电压是否超出 0.95–1.05 p.u. 计算。两项指标越小越好，最低和最高电压另报。
- PPO 首轮预训练 1,500 日回合，种子 42。LLM 起步和反思共涉及 209 个不同训练日，后续用另外 150 个训练日的冻结计划微调 PPO。
- 控制效果实验的 LLM 为 DeepSeek-V4.1-Flash-1017，原批次通过官方 API 调用，关闭 thinking。后续默认入口切到智算云，完成型号、合法计划与潮流接口检查。已保存的实验计划直接复用。
- 以下主结论来自当前 33 节点系统和单训练种子，最终测试集留待方案冻结后使用。

## 同一批 181 日的联合方案

所有有检索的方案共用同一批已保存 LLM 计划；无检索的 LLM 单独生成计划，两类都使用同一份日期预测。

|---|---:|---:|
| LLM 无检索、零无功 | 0.021594 | 6.394% |
| LLM 有检索、零无功 | 0.018140 | 3.709% |
| LLM 有检索＋预训练 PPO | 0.010817 | 0.830% |
| LLM 有检索＋微调 30 回合 PPO | 0.010797 | 0.829% |

加预训练 PPO 后，相对相同 LLM 计划下零无功组，平均偏差降低约 40.4%，越限率相对降低约 77.6%。微调 30 回合的平均改善仅 0.184%，48 天变好、133 天变差，主要依靠少数日子的较大收益。微调 60 回合的越限率最低，最严重欠压也有所改善，但平均偏差升高。现阶段保留预训练 PPO 作主要参照，阶段权重均保留，最终测试前再确定使用版本。

## 改进方向与优先级

1. **先做一个受控的 PPO 训练设置对照。** 现有回放表明部分时段能通过改变动作改善，阶段验证表明直接延长当前微调路径收益有限。建议复用相同计划、日期和初始权重，先只降低学习率，保留阶段权重。同步看原策略均值、动作裁剪和饱和比例，以判断参数更新怎样改变了动作。MLP 加宽、修改观测或奖励需另设实验，分别判断贡献。
2. **把平均偏差与越限的取舍显式报告。** 论文原奖励主要针对全网平均绝对偏差，后续如增加越限罚项，应作为新版本与原奖励对照，记录两项指标和最严重电压。
3. **补强优化参照的 AC 可行性。** 先处理普通日联合解回代过压，核对锥松弛、电压平方目标和实际 AC 目标的差异。强光伏日同时检查无功限值、机械调节及当前假设下的可行性。设备增容、弃光等若要引入，单列系统配置对照。
4. **LLM 暂保留 16 条经验和 0.7 更新阈值。** 检索在高低相似度组都有收益。扩库或提高阈值应使用相同训练日顺序、初始库、调用预算和验证集。反思对照还需考虑四次无反馈生成选优，区分反馈与额外采样的作用。
5. **冻结配置后补关键基线和多种子测试。** 优先 No-PT（同一批 LLM 计划、相同微调预算、随机初始化 PPO）和完整 No-LLM 验证，再补 Pure-RL 和完整 No-Reflexion。跨训练种子报告均值和波动，最终打开 184 日测试集。

完整方法的工程链路已跑通，PPO 控制和经验检索均有实测贡献；论文宣称的微调优势仍未在当前配置下稳定复现。当前使用替代数据、单训练种子和不同 LLM 服务，结果用于本项目复现评价。
