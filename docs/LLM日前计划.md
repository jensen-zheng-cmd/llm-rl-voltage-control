# LLM 日前计划

入口为 [run_llm_planning.py](../scripts/run_llm_planning.py)。使用项目 Python 运行，通过 `--key-file` 指定仅含一行密钥的本地文件，通过 `--output` 指定新的运行目录。当前默认使用智算云 Chat Completions JSON 模式，模型 ID 为 `DeepSeek-V4.1-Flash-1017`，使用智算云密钥文件。关闭 thinking，temperature 0.7，top_p 0.8。此前批次使用 DeepSeek 官方 API；如需复跑官方入口，在当前终端设置 `$env:LLM_PROVIDER = "deepseek"`，并传入对应的官方密钥文件。运行记录分别注明供应商和模型。

| 阶段 | 参数 | 工作内容 |
|---|---|---|
| 接口检查 | `--stage smoke` | 一个普通训练日，一次生成 |
| 起步经验库 | `--stage seed` | 两个普通、两个高峰负荷、两个高峰光伏训练日。初稿与中性计划同日评分后选优 |
| 反思试验 | `--stage pilot --pool <seed/pool.json>` | 三个额外训练日，初稿加三轮反思 |
| 正式改进 | `--stage formal --pool <pilot/pool.json>` | 200 个另外的训练日，同样进行三轮反思 |

- 先算各通道小时均值，再按种子 42 与日期派生独立相对正态误差（标准差 5%），聚合到区域。各轮复用同一预测。潮流使用未加噪的 96 步时序，PV 无功置零。
- 档位和电容器计划由程序严格检查。重复指定当前档位在物理上无动作。无效计划允许两次约束纠错，纠错与潮流反馈后的 Reflexion 分开记录。
- 日奖励为 96 步节点平均负绝对电压偏差之和。程序同时保存越限率、最严重过欠压、每小时逐节点平均电压。
- 检索使用全网净负荷预测的余弦相似度乘绝对日总量的幅值相似度。低于 0.7 新增，高于或等于 0.7 比较原记录和当前记录的日奖励。两条曲线均为零时记为相同，单条为零或幅值分母为零时记为 0。
- 每日目录保留预测、每次请求与响应、计划与评分。只有训练日进入库。正式库冻结后的验证和 PPO 微调各自独立开展。
