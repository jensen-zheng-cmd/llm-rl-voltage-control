# 三个训练种子的测试集结果（阶段 E3）

2026-11-12 完成。按 [v2 测试规程](../../docs/v2测试规程.md) 打开划分 A 的 48 个测试日，3 个种子 × 7 种方法全部评估。方法、模型版本（全部第 150 回合）、经验库和超参数都沿用 T22 验证时的冻结版本，打开测试集后没有做任何修改。

## 口径

- 经验库冻结，测试时不做 Reflexion，也不更新经验库。每个种子测试时用的两个经验库，与该种子验证时用的文件逐字节相同（SHA-256 一致）。
- 每个种子、每个测试日，Proposed 库和 No-Reflexion 库各调用 LLM 1 次。检索取最相似的经验日，即使相似度低于阈值也照用。No-RL、No-PT 和 Proposed 共用同一份 Proposed 计划。
- Pure-RL 的日前代理和 PPO 策略都取确定性动作。PV 无功按逆变器容量裁剪。
- "均值 ± 标准差"指：每个种子先对 48 天取平均，再在 3 个种子之间求均值和样本标准差。逐日配对先对 3 个种子取平均，再在 48 天上算差值和标准误。

## 结论

1. **测试集确认了验证集的结论。** Proposed 在 3 个种子上都最好，7 种方法的排序和验证集完全一致。Proposed 的平均偏差从验证集的 0.009545 变为测试集的 0.009751，高约 2%；Original 也高约 2%，说明测试日本身稍难。
2. **相对各对照的降幅：** No-RL 低 42%，No-PT 低 37%，Pure-RL 低 19%，No-LLM 低 9.8%，No-Reflexion 低 3.9%。前五项的差距都远大于种子间波动。
3. **Reflexion 的收益在测试集上变小，但方向不变。** 和 No-Reflexion 的差距从验证集的 0.00052 降到 0.00040，Proposed 更好的天数从 40/48 降到 35/48。3 个种子都是 Proposed 更低。种子 44 上 No-Reflexion 的无越限天数（39）反而多于 Proposed（36）。
4. **微调的贡献小。** 和预训练未微调的模型比，平均偏差降 1.5%，40/48 天更低，越限率基本相同。
5. **和论文次序的差别与验证集相同。** No-PT 排第五（论文第三），原因是从头训练 150 回合远未收敛。Pure-RL 排第三到第四（论文倒数第二），并且种子间波动最大。
6. **量级：** Proposed、No-Reflexion、No-LLM 的平均偏差和论文同一量级（约 1.0e-2）。越限率仍明显高于论文：Proposed 0.13%，论文 0.0026%。Proposed 的最高电压仍到 1.076 p.u.。

## 边界

- 每个种子在每个测试日只做一次 LLM 采样。
- 标准差只基于 3 个种子。逐日配对的标准误只反映日期之间的波动。
- MISOCP 参照另行记录，不在本目录。
