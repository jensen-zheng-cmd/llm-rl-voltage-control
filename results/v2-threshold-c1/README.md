# 经验库阈值离线模拟 C1（v2、划分 A）

2026-11-09 完成。只用划分 A 的 221 个训练日，对经验库更新阈值 0.70、0.80、0.85、0.90 做离线模拟。
没有调用 LLM API，没有训练 PPO，没有用验证日或测试日计算指标，也没有评价控制效果。

## v2 的论文式信息口径

- 预测先按论文区域拓扑汇总为每个区域的小时净负荷（P 负荷减 PV），再独立加入相对标准差 5% 的乘性高斯噪声。
- 全网净负荷是加噪后三个区域的逐小时总和，保持内部一致；净反送保留负号，不截成零。
- 论文只说 5% 白噪声，没有规定分布和乘/加操作，因此这些是显式实现假设，不冒充作者原设定。
- Reflexion 的新 v2 反馈函数只保留总奖励、各区域及全网的小时平均电压，不传节点级电压或越限节点。
- v1 的原预测、反馈和结果不改。新增测试确认 v1 对冻结历史日重新生成的预测与已保存记录一致。
- 本目录中的相似度仍使用项目既定规则：全网净负荷曲线的余弦相似度乘绝对日总量的幅值相似度。

## 模拟方法

每个阈值都从空的代理经验库开始，按日历顺序遍历全部 221 个训练预测：

- 最相似度低于阈值就新增一条代表经验；
- 达到阈值就归入已有代表，条数不变；
- 不模拟奖励决定的经验替换，因为 C1 不生成计划，也不计算奖励。

最终再用这个代理库回溯检索 221 个训练预测，统计最近邻相似度。高光伏日定义为“六台 PV 合计日内有功峰值位于训练集前 20%”，共 45 天。

## 结果

| 阈值 | 最终代理库条数 | 归入已有经验的天数 | 高光伏代表条数 | 全部训练日的最近邻相似度中位数 / 最小值 | 高光伏日的最近邻相似度中位数 / 最小值 |
|---|---:|---:|---:|---:|---:|
| 0.70 | 15 | 206 | 10 | 0.8718 / 0.7043 | 0.8621 / 0.7741 |
| 0.80 | 28 | 193 | 15 | 0.9205 / 0.8266 | 0.9547 / 0.8266 |
| **0.85** | **40** | 181 | 17 | 0.9376 / 0.8680 | 0.9571 / 0.8793 |
| **0.90** | **60** | 161 | 20 | 0.9575 / 0.9006 | 0.9708 / 0.9006 |

四档回溯时，高光伏日达到相似度至少 0.70 的比例都是 100%。因此本场景没有明显的“高光伏日完全找不到相近经验”问题，主要区别是经验库的精细程度。

**C2 两档建议：0.85 和 0.90。** 0.85 对应 40 条，是较稀疏档；0.90 对应 60 条，覆盖更细，符合此前约 40–80 条的讨论目标。这里的选择只看训练日覆盖和规模，没有任何电压控制结果参与。

## 边界

C2 实际建库使用 200 个训练日，且会根据奖励替换经验，因此实际库条数不一定等于这里的 40/60。
C1 只负责选两个有差异的候选阈值，不能据此宣告某档的电压效果更优。新 v2 反馈函数已做单元检查，尚未用于任何真实 LLM 调用。
