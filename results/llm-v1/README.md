# LLM 日前计划首轮结果

[方法与运行入口](../../docs/LLM日前计划.md) · [三日试验](pilot.csv) · [正式训练逐日结果](formal_days.csv) · [冻结经验库](frozen_pool.json)

首日接口跑通 96 步。六日起步库各保留了三张模型初稿和三张中性计划。三日试验的最佳计划日奖励均改善，一天越限率从 4.830% 升至 4.987%。

正式批次使用 200 个训练日，共评分 800 张模型计划。库从 6 条增至 16 条，新增 10 条、替换 38 次。反思选优相对初稿使平均日奖励从 −1.704 提升至 −1.626，平均越限率从 2.21% 降至 1.62%。含起步和试验共用 209 个不同的训练日，其余 522 日未用于 LLM 建库或更新。

## 独立验证

[181 天逐日配对](validation_pairs.csv) · [分组摘要](validation_summary.json)

每个验证日用同一预测分别生成有检索和无检索的计划，两组均关闭 Reflexion、PV 无功置零。用于验证的 16 条经验与正式批次最终库的文件哈希一致。

| 验证日 | 平均电压偏差（p.u.），无检索 → 有检索 | 越限率，无检索 → 有检索 |
|---|---:|---:|
| 全部 181 天 | 0.02159 → 0.01814 | 6.39% → 3.71% |
| 相似度 ≥ 0.7，158 天 | 0.02137 → 0.01803 | 5.98% → 3.37% |
| 相似度 < 0.7，23 天 | 0.02313 → 0.01893 | 9.27% → 6.03% |

170 天电压偏差改善，151 天越限率改善，21 天越限率升高。全体最严重欠压从 0.9238 降至 0.9224 p.u.。每个日期每种条件只生成一次，结果对应本批模型及采样参数。

现阶段冻结此库，0.7 继续用于训练阶段的经验更新。提高阈值对库覆盖和调度效果的影响留作对照实验。完整运行档案位于 D:\Codex\outputs\llm-rl-voltage\runs，正式目录名为 llm_v1_1793690332319_formal，验证目录名为 llm_retrieval_validation_1793702590987。
