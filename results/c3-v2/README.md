# C3 划分 B 检索对照

2026-11-12 完成并汇总，已验收（T25）。沿用 Factory Droid 已完成的建库和验证产物；接手后只核验、汇总，没有重新训练、调用 LLM 或修改冻结的方法。

## 比较口径

- A：有隔离日的半月划分，沿用 T19 的 0.90 库及 48 日验证。
- B：4 天训练、1 天验证、1 天测试的循环，无隔离日；6 个起步日加 200 个正式训练日，阈值 0.90、每天初稿加 3 轮 Reflexion，随后冻结库，在全部 61 个验证日上比较有经验和无经验。
- 两组共用 v2 设备容量、预测噪声种子、提示词和 LLM 参数。模型为 DeepSeek-V4.1-Flash-1017，temperature 0.7、top_p 0.8；验证时关闭 Reflexion，每天每组只采样一次。
- 评分使用同一 AC 潮流环境，PV 无功为零，没有接入 PPO。电压为 p.u.，参考节点为 1、相角为 0；负荷与发电沿用项目 MW/MVAr 及向网络注入为正的约定。
- 收益定义：同一天“无经验 LLM 的平均绝对电压偏差”减“有经验 LLM 的偏差”；正数表示检索有益。相对收益为两者的日均差除以无经验组日均偏差。
- B 在 A 的三种子测试评估完成后才开始，避免 B 的训练日期提前暴露 A 的测试数据。B 的测试日没有用于本次验证，也没有在 B 上训练 PPO。

## 结果

| 指标 | A（T19） | B（C3） |
|---|---:|---:|
| 验证日 / 最终经验条数 | 48 / 54 | 61 / 57 |
| 中性计划平均偏差 | 0.020793 | 0.020974 |
| 无经验 LLM 平均偏差 | 0.020477 | 0.020631 |
| 有经验 LLM 平均偏差 | 0.016485 | 0.016804 |
| 检索收益（日均 ± 日期标准误） | 0.003992 ± 0.000364 | 0.003826 ± 0.000375 |
| 相对收益 | 19.50% | 18.55% |
| 有经验偏差更低 / 更高天数 | 46 / 2 | 57 / 4 |
| 无经验 → 有经验越限率 | 4.862% → 2.111% | 4.233% → 2.166% |
| 越限率降低（百分点） | 2.751 | 2.067 |

B 的绝对检索收益比 A 少 0.000166 p.u.，相对收益少 0.95 个百分点。本轮没有观察到无隔离日的 B 收益更高；这也不证明两种划分等效。

## 事后诊断：日期距离

日期距离分组和相似度关联属于事后分析，不用于选择模型或替换 A 的测试结果。

| 指标 | A | B |
|---|---:|---:|
| 实际检索日期距离中位数（天） | 41.5 | 58.0 |
| 实际检索到相邻 1 天样本 | 0/48 | 0/61 |
| 实际检索日期相距 2–7 天 | 4/48 | 5/61 |
| 库中存在相邻 1 天样本 | 0/48 | 12/61 |
| 库中最近日期距离中位数（天） | 5 | 3 |

虽然 B 允许训练日紧邻验证日，库也确实为 12 个验证日保留了相邻样本，但相似度检索没有选择这些相邻样本。现有结果支持“本轮 B 的检索收益没有更高”，无法回答“实际检索到相邻日时，收益会不会被抬高”。

## 核验与边界

- B 的 6 个起步日、200 个正式日与各自配置逐日一致，全部属于 B 训练集；正式阶段新增 51 条、替换 63 次、保留 86 次，最终 57 条。
- 61 个验证日齐全、无重复；冻结库哈希与建库输出一致，所有检索日期都在冻结库中，库内没有 B 验证或测试日期。
- B 的起步 / 正式建库 / 验证分别保留 24 / 800 / 122 次响应记录，共 946 次，没有格式修复。验证没有使用中性计划回退，日志未见 Traceback 或 MemoryError。
- 汇总脚本核对两组验证日期集合、冻结库哈希、库内日期和检索引用，并核对两组 LLM、预测、提示词和评分相关参数一致。输入文件的 SHA-256 保存在 summary.json。
- A 的结果重算与 T19 一致。接手检查时，项目自动测试为 25 项通过；本次另从逐日 CSV 独立重算两组收益并核对汇总。没有重跑 AC 仿真或优化求解。
- 每组只建了一个库、每天每组只采样一次。日期标准误只描述日期间波动，不包含建库和 LLM 重复采样的不确定性，也没有校正日期间相关性。
- A、B 有 7 个重叠验证日，且日期组成、库大小和内容不同，不能把组间差异单独归因于隔离日。summary.json 保留的独立性假设标准误（0.000522）仅为带假设的参考量，不作显著性检验。
- 本次没有证明存在泄露，也没有证明不存在泄露。若要识别相邻日的影响，可另立实验，在同一批验证日上比较允许/排除相邻经验、并重复建库和 LLM 采样；本轮未执行该扩展。
