# 三个训练种子的验证集结果（阶段 E2）

2026-11-12 完成。按 [v2 测试规程](../../docs/v2测试规程.md)，种子 43 和 44 完整重建全部方法：PPO 预训练、Proposed 与 No-Reflexion 两个经验库、Pure-RL 日前代理、全部微调和联合验证。种子 42 沿用 T20、T21 的结果。评估在 48 个验证日上进行，**测试集未打开**。

## 口径

- 每个种子改变的是 PPO 的初始化与采样，以及 LLM 调用自身的随机性。预测噪声、建库日顺序、6 个起步日、150 个微调日都与种子 42 相同。
- 方法定义、模型版本（全部第 150 回合）和超参数都按规程冻结，没有根据验证结果改动。
- 下表中的"均值 ± 标准差"指：每个种子先对 48 天取平均，再在 3 个种子之间求均值和样本标准差。
- 逐日配对的做法是：先对 3 个种子取平均，再在 48 天上算差值和标准误。标准误只反映日期之间的波动。

## 结论

1. **Proposed 在 3 个种子上都是最好的。** 相对 6 个对照，平均偏差都更低：No-RL 低 42%，No-LLM 低 10%，No-Reflexion 低 5.2%，Pure-RL 低 15%。这些差距都明显大于种子间的波动，Proposed 本身的标准差是 0.000128。
2. **Reflexion 的作用稳定。** No-Reflexion 在 3 个种子上都排第二。它和 Proposed 的差距（0.00052）约为种子标准差的 4 倍，40/48 天 Proposed 更好。
3. **微调的贡献小，但方向稳定。** 和预训练未微调的模型相比，平均偏差降 2.1%，46/48 天更低，3 个种子都如此。这和 T20 单种子时的结论一致，只是现在可以确认它不是偶然。
4. **和论文次序不同的地方，在 3 个种子上都存在。**
   - No-PT 在论文中排第三，本项目稳定排第五。原因是从头训练 150 回合远未收敛，这个对照只说明有限微调预算下的结果。
   - Pure-RL 在论文中排倒数第二，比 No-RL 还差；本项目排第三到第四。它的波动也是各方法中最大的，种子 44 的日前计划明显更差，使最终结果变成 0.012509。这和 T21 的判断一致：本项目的日前代理设计可能比论文的更容易学。
5. **量级方面，** Proposed、No-Reflexion 和 No-LLM 的平均偏差与论文接近，在 1.0e-2 左右。越限率仍高于论文，Proposed 是 0.073%，论文是 0.0026%。

## 边界

- 结果只来自验证集，测试集和 MISOCP 参照都还没做。
- 每个种子在每个验证日只做一次 LLM 采样。
- 标准差只基于 3 个种子。
- 种子 42 的 Pure-RL、No-Reflexion 与 Proposed 来自 T20、T21 的运行，用改过的代码重算后逐项一致（见 T22 记录）。
