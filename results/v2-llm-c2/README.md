# LLM 经验库建库与冻结验证 C2（v2、划分 A）

2026-11-10 完成。用智算云 `DeepSeek-V4.1-Flash-1017`（关闭 thinking，temperature 0.7，top_p 0.8），按论文流程分别以阈值 0.85、0.90 建库，再在 48 个验证日上比较冻结经验库与无经验。测试集未打开。

## 口径

- LLM 输入：`forecast_v2` 的区域与全网小时净负荷预测（先区域聚合，再加 5% 乘性高斯噪声）。提示词补充三个区域的节点、电容器和 PV 位置。
- LLM 反馈：`feedback_v2` 只给总奖励和区域/全网小时平均电压，不给节点级电压或越限节点。
- 评分：环境使用真实 15 分钟数据，PV 无功置零，即 No-RL 口径。奖励为 96 步节点平均绝对偏差之和取负。
- 相似度：论文式 14–16，即全网净负荷预测的余弦趋势相似度乘日总量幅值比。
- 日期：起步 6 天（2 普通、2 高负荷、2 高光伏，两档共用，全部入库，不检索）；正式 200 天按固定种子 2026 随机排序；另有 3 天只用于小试，不进入正式库；其余 12 天未用。
- 每天流程：检索最相似经验 → 初稿 → 3 轮 Reflexion → 4 个候选取最高奖励 → 相似度低于阈值新增，否则奖励更高才替换。
- 验证：经验库冻结，关闭 Reflexion，每天每组只生成 1 次；检索取最近邻（低于阈值也用）；三组生成顺序按日期轮换。随机性留到阶段 E 用 3 个独立种子处理。

## 48 个验证日

| 组别 | 平均偏差（p.u.） | 越限率 | 最低 / 最高电压（p.u.） |
|---|---:|---:|---:|
| 中性计划（档位 0、电容器全关） | 0.020793 | 5.27% | 0.9284 / 1.1101 |
| LLM 无经验 | 0.020477 | 4.86% | 0.9257 / 1.1076 |
| LLM＋0.85 库（37 条） | 0.016574 | 2.25% | 0.9320 / 1.1076 |
| LLM＋0.90 库（54 条） | 0.016485 | 2.11% | 0.9257 / 1.1076 |

逐日配对：

- 0.85 库相对无经验：平均偏差降低 0.003903（标准误 0.000446），45 天降低、3 天升高；越限率降低 2.61 个百分点，37 天降低、7 天升高。
- 0.90 库相对无经验：平均偏差降低 0.003992（标准误 0.000364），46 天降低、2 天升高；越限率降低 2.75 个百分点，39 天降低、6 天升高。
- 0.85 减 0.90：平均偏差差 +0.000089，标准误 0.000244，27 天 0.85 更低、21 天 0.90 更低。按事先约定（差小于 2 倍标准误），**两档没有可分辨的差异**。
- 无经验的 LLM 与中性计划接近，18 天偏差比中性计划更大。检索最近邻的平均相似度：0.85 库 0.908，0.90 库 0.924；最低都是 0.679。

## 结论

冻结经验库带来的改善明显且稳定，两档都把平均偏差降低约 19%，越限率降低一半以上。0.85 和 0.90 之间的差距在单次采样的噪声范围内。0.85 库更小，0.90 库覆盖更细，进入阶段 D 选哪一档需要另行讨论。

## 边界

- 单个 LLM 采样种子，验证每天每组只生成 1 次。
- 评分时 PV 无功为零，没有接入 PPO；联合效果属于阶段 D。
- 三组的最高电压都是 1.1076 p.u.，说明有高光伏时段仅靠机械设备无法压住过压，需要 PV 无功配合。
- 噪声分布和乘性形式是本项目的实现假设，论文没有给出。
