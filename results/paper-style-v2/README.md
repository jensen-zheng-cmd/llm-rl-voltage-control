## 训练图口径

- 三个种子 42、43、44。每个种子先计算 25 回合向后滑动均值，再画跨种子的均值与样本标准差。
- 横轴为 200 个正式日前训练回合与 150 个日内微调回合，合计 350；与原图相同，在第 200 回合处分阶段。6 个起步建库日、1,500 回合 PPO 预训练和价值网络预热不放入这段横轴。这是本图相对早先 356 回合图的显示范围调整。
- 每日奖励乘 33，得到节点与时段上绝对电压偏差之和的负值，与原图 7 的量纲对应。原始数值未做幅度归一化或趋势修饰。
- No-Reflexion 按原图只展示日前阶段；No-PT 只展示微调阶段。No-PT 的滑动均值沿用共同的 Proposed 日前历史跨阶段衔接，不把这段历史另算为 No-PT 观测。
- 所有实际正式回合保存在 `fig7_training_raw.csv`，图上均值和 SD 在 `fig7_training_mean_sd.csv`。

## 执行表口径

- 七种方法使用 48 个测试日 × 3 个种子，共 144 个日回合，计算每日指标的均值和样本标准差。MISOCP 使用 48 个测试日。
- 这里 Std. 表示日回合之间的离散程度，与原表 III 的日回合统计对象对应；早先报告的“三个种子均值的 SD”是另一项统计，不能填入本表。
- Original 在各个种子下使用同一组确定性日结果，重复记录不代表额外独立日期。本表仅报告描述性均值和 SD，不计算显著性。
- 均值逐项与 T23/T24 匹配。粗体标记除 MISOCP 外每列的最小值，规则与原文一致。
- 原始日回合在 `table3_daily_episodes.csv`；完整精度汇总在 `table3_execution.csv`。
