# 四个验证日的电压对比

按 181 个验证日的全网功率峰值选取高负荷、最高光伏和最大净反送三天，沿用 5 月 22 日的普通日作参照。所有电压指标均来自 AC 回代。

| 日期 | 选日依据 | 预训练 PPO 平均偏差 / 越限率 | 固定计划 SOCP | 联合 MISOCP |
|---|---|---:|---:|---:|
| 2014-05-22 | 普通日 | 0.01106 / 0% | 0.00859 / 0% | 0.00600 / 0.063% |
| 2014-02-04 | 峰值负荷最高 | 0.01273 / 0.505% | 0.00966 / 0.505%（软限值） | 0.00687 / 0% |
| 2014-05-29 | 峰值光伏最高 | 0.01284 / 3.378% | 0.01074 / 3.472%（软限值） | 0.01020 / 2.967%（软限值） |
| 2014-05-05 | 最大净反送 | 0.01221 / 3.220% | 0.00989 / 3.283%（软限值） | 0.00960 / 2.462%（软限值） |

标注软限值的模型对应的 0.95–1.05 p.u. 硬限值模型不可行。软限值用于诊断和对照。联合优化在两个强光伏日仍有过压。

普通日联合计划夜间档位 +2，晚间最高 +3，入口电压范围 1.000–1.018 p.u.。AC 回代的 96 个时段均同时存在高于与低于 1.0 p.u. 的节点。12:15 的 Original 工况向上级反送 3.639 MW，但支路 28→29 仍下送 0.191 MW 和 0.682 MVAr，29 号节点 0.99977 p.u.，18 号节点 1.09000 p.u.。
