# PPO 预训练 v2（划分 A，阶段 B）

2026-11-09 完成。在 v2 配置（只用 2013 年数据、划分 A、光伏不缩放、逆变器容量为 1.2 倍训练峰值）上，
按论文设置和改进设置各预训练一组集中式 PPO，种子 42，各 1500 回合。

## 两组设置

| 项目 | 原设置（original） | 改进设置（improved） |
|---|---|---|
| 初始探索标准差 | 1.0（论文同 SB3 默认） | 0.37 |
| 每次更新收集 | 384 步（4 天） | 960 步（约 10 天） |
| 小批量大小 / 训练轮数 | 32 / 4 | 32 / 4（不变） |
| 学习率 | 1e-4 → 1e-5 线性衰减（两组相同，同论文） | 同左 |
| 网络 | pi/vf 各 [256, 256]，Tanh（两组相同） | 同左 |
| 采样更新轮数 | 375 | 150 |

两组的梯度步数相同（各 18000 步），差别只在探索噪声幅度和每次更新的批量天数。

## 最终结果（48 个验证日，固定随机机械计划，种子 2026）

| 指标 | 零无功基线 | original | improved |
|---|---|---|---|
| 平均电压偏差 (p.u.) | 0.021811 | 0.012542 | **0.012242** |
| 越限率 | 6.995% | 0.633% | **0.597%** |
| 最低电压 (p.u.) | 0.9128 | 0.9354 | 0.9336 |
| 最高电压 (p.u.) | 1.1152 | 1.0778 | 1.0784 |

- 逐日对比见 `validation_original.csv` 和 `validation_improved.csv`。improved 在 48 天中的 34 天偏差更小；
  出现越限的天数为 19 天，少于 original 的 34 天。最差的一天（2013-12-28，高负荷日）improved 略差
  （0.0325 对 0.0314）。
- 训练动态：original 的探索标准差几乎不收缩（1.001 → 0.947），improved 稳定在 0.37 → 0.353。
  价值网络拟合度（explained variance）结束时 original 0.68、improved 0.63，后半程出现负值更新的比例
  分别为 13% 和 0%。improved 前期学习更慢（300 回合时 0.0198 对 0.0148），约 900 回合后反超，
  与更小的探索噪声和更大的批量一致。
- 单组训练约 2 小时 17 分，两组并行。模型保存并重载校验通过（逐元素一致）。

## 结论

1. v2 场景下两组 PPO 都把平均偏差从 0.0218 降到约 0.0122–0.0125，越限率从 7.0% 降到约 0.6%，
   说明场景可控且 PPO 能学到有效策略。
2. 改进设置最终以较小优势胜出（偏差 −2.4%，越限天数 34 → 19），且价值网络在整个训练中都保持健康
   （无负值更新）。代价是前期收敛慢。
3. 原设置中观察到的"标准差不收缩"现象在 v2 仍然存在（0.947），改进设置正是针对这一点。
