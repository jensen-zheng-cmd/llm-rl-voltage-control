后三天用固定机械计划的 SOCP 软电压限值解。全部电压指标由原 AC 潮流计算。

选每日电压偏差差距最大的三个相隔至少一小时的时段，以及优化后剩余的最严重欠压或过压时段。逐个将 PPO 的一台逆变器无功换成 SOCP 同时刻指令，其他五台保持 PPO 指令，再做 AC 潮流。该替换仅用于诊断当时电压响应。

- **05-22 17:45**。18 号逆变器由注入 0.546 改为吸收 0.310 MVAr，单独替换就把全网当步平均偏差由 0.01436 降到 0.00803 p.u.。六台一起替换为 0.00687 p.u.。
- **02-04 14:45**。13 号逆变器由吸收 0.479 改为注入 0.544 MVAr，单独替换把偏差由 0.02514 降到 0.01157 p.u.。六台一起替换为 0.00697 p.u.。
- **02-04 21:00**。两套方案的六台逆变器均已最大注入，最低电压仍约 0.94686 p.u.。
- **05-29 11:45、05-05 11:30**。两套方案的六台逆变器均已最大吸收，18 号节点仍约为 1.09886 和 1.10698 p.u.。

这四天同时存在可通过改变无功方向改善的时段，以及无功已用尽的时段。单台替换能说明选定时刻的动作影响，训练量或观测设计的影响需要单独验证。
